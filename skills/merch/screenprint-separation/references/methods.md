# Методы цветоделения и подготовки — параметры и грабли

## 1. Плоский макет (sep_flat.py)
- Растеризация без сглаживания: `pdftoppm -r 400 -png -aa no -aaVector no src.pdf hi` — иначе на стыках появятся промежуточные цвета.
- Палитра: `np.unique` по пикселям, сортировка по частоте; цвета < 0,1% площади — шум. Ещё признак «цветов больше, чем кажется»: в байтах PDF есть `/Separation`, `/DeviceN`, `Indexed`, градиенты (`/ShadingType`).
- Маски по точному HEX с допуском ±2 по каналам. Контроль: доля пикселей, не попавших ни в одну маску и не белых, ≈ 0.
- Треппинг 0,25 мм (при 400 dpi это 4 px, ядро-эллипс 9×9): каждый цвет расширяется только в зону более поздних (тёмных) цветов. Последний (контур) не расширяется.
- Подложка для тёмной ткани = объединение всех цветов, кроме тех, что заменяет ткань (тёмный контур), с чоком 0,1 мм (erode 3×3 при 400 dpi).
- Векторизация: `cv2.findContours(RETR_CCOMP)` + `approxPolyDP(0.6 px)`, заливка even-odd (`fillMode=0` в reportlab) — дырки остаются дырками.
- Метки совмещения: круг r = 3 мм с крестом, 6 штук (углы + середина верх/низ), поле 18 мм.
- Экраны: белая футболка = число цветов (почти белый можно не печатать — это ткань); бежевая в тон фона — минус фон; чёрная = цвета без контура + подложка.

## 2. Тоновый арт (sep_tones.py)
- Серый, низкое разрешение, скриншот: `GaussianBlur(0.6)` → `np.digitize` по порогам → острова < 3 px заменить медианой 3×3 (2 прохода) → `potrace`.
- Пороги: multi-Otsu по пикселям арта (без фона) как старт, финал — на глаз по `preview_posterized.png`. В примере с тоновым артом (пример 2 в examples.md) итог 55/120/185.
- potrace: библиотека `potracer` ИНВЕРТИРУЕТ вход — передавай `~mask`, иначе контуры наизнанку. Параметры: `turdsize=2, turnpolicy=MINORITY, alphamax=1.0, opticurve=True, opttolerance=0.2`.
- Треппинг 1 px (≈ 0,2 мм при 0,2 мм/px): светлая краска заходит в соседнюю тёмную печатную.
- Чёрная футболка: подложка не нужна, если кроющий пластизоль; порядок тёмно-серый → светло-серый → белый. Pantone ориентиры: Cool Gray 11 C, Cool Gray 8 C.
- Масштаб: задаёшь высоту принта (`--height-mm`), вектор масштабируется без потерь.
- Предложи дешёвый вариант на 2 краски (серый + белый), если 3 не обязательны.

## 3. Фото и полутона (2 краски растром)
- Для фото «в точности»: 2 краски + ткань, растр AM 45 lpi, круглая точка, угол 22,5° у обеих (без муара), сетка 77–90 нитей/см.
- На чёрной футболке: серый (≈ Cool Gray 7 C) первым с флэшем, белый вторым поверх; тени чуть затемнить — точка растекается на ткани.
- Выход: PDF превью на чёрном + 2 плёнки «позитив 1:1 · AM 45 lpi, 22,5°, круглая точка · чёрная футболка не печатается».
- Мелкая «пыль» меньше точки растра пропадает — точнее только ДТФ. Скажи это до работы.

## 4. Реконструкция плохого растрового логотипа
Трассировка JPEG даёт рваные края. Работало так:
- Центр и радиус диска — МНК по окружности (`scipy.optimize.least_squares`, `soft_l1`) по точкам края, найденным сканом лучей; масштаб: известный диаметр (250 мм) / радиус в px.
- Отверстия, кольца — окружности по найденному центру и углу (шаг 30°), каждое уточнить МНК.
- Буквы — шрифтом (LiberationSans-Bold), ширина каждой буквы растягивается до измеренного bbox, высота заглавных по замеру.
- Глаза — эллипс по моментам маски (`np.cov` → собственные векторы), а не `EllipseModel` (он давал сбои); рот — скелет маски → самый длинный путь (networkx) → сплайн → буфер постоянной толщины.
- Геометрия в `shapely`, слои = разности фигур (серебро = силуэт − отверстия − лицо − блик). Градиенты металла — тёмно-серая краска растром.
- Покажи превью рядом с исходником и получи «ок» до плёнок.

## 5. Текст в кривые (text_curves.py)
- fontTools → BasePen → `canvas.beginPath()`; ширина по чернилам (bounds глифов), высота = capHeight × k.
- Шрифт из npm: `npm pack @fontsource/<name>`, файлы `package/files/<name>-cyrillic-800-normal.woff` (кириллица) и `-latin-…` (латиница: буквы M/L/XL — из латинского файла, иначе глифов нет).
- Проверка: `pdftotext файл.pdf -` пусто; `pypdf` → размер страницы в см = `mediabox.width / 72 * 2.54`.

## 6. Грабли
- Helvetica в reportlab без кириллицы → подписи квадратиками. Регистрируй DejaVu.
- Легенда цветов наезжает при 6+ цветах — в 2 ряда.
- `pkill -f` в песочнице может убить свою оболочку; останавливай процессы по PID.
- Выход PDF держи векторным; растр — только превью.
