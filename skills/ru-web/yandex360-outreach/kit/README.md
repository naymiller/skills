# Папка рассылки (кладётся на Мак, например outreach/<проект>/sender/)

Письма уходят с ящика Яндекс 360 по SMTP; ответы, отписки и недоставленные скрипт проверяет по IMAP и сам останавливает цепочку.
Пароль приложения хранится только в Связке ключей macOS — не в файлах, не в чате.

## Один раз
1. Скопируй `config.example.json` в `config.json`. Впиши адрес ящика в `login` и в `mailboxes`, имя отправителя в `from_name`, домен в `own_domains`, имя PDF с КП в `kp_file`.
2. Яндекс Почта → Настройки → Почтовые программы → включить IMAP и «Пароли приложений и OAuth-токены».
3. id.yandex.ru → Безопасность → Пароли приложений → тип «Почта». Создавать, войдя именно в этот ящик (иначе `535 Invalid user or password`).
4. Двойной клик `setup.command` → вставить пароль (символы не видны) → придут тестовые письма себе. Проверить входящие и папку «Спам».
   Если macOS не открывает `.command`: правый клик → «Открыть».

## Каждый рабочий день (ручной режим)
`send_today.command`: проверит входящие, покажет очередь на сегодня, отправит только после слова `да`, выведет сводку и обновит `crm/crm.csv`.

## Автозапуск (после первой волны вручную)
1. Убедись, что первая волна ушла через `send_today.command` без ошибок в логе.
2. Сам поставь в `config.json`: `"auto_send_approved": true`.
3. `auto_on.command` — launchd: отправка пн–пт 11:07, проверка ответов каждый час 9:45–18:45. Без пункта 2 скрипт откажется включаться.
4. `auto_off.command` — выключить.
Cron не использовать: он не видит Связку ключей. Мак не должен спать в эти часы.

## Файлы
- `emails_wave1.csv` — все письма: компания × 4 касания (собирает `build_emails.py` из `emails_template.md` и `leads.csv`; формат — `leads_example.csv`).
- `outreach_log.csv` — журнал отправок; `lead_status.json` — ответил / отписался / недоставлено.
- `replies/` — ответы по файлу на письмо; `mailbox_alerts.txt`, `mailbox_state.json` — паузы ящиков.
- `crm/crm.csv` — CSV-CRM, пересобирается `crm_sync.py`. Ручные поля `manual_stage`, `amount`, `notes` не затираются.
- `history/threads.json`, `history/threads.md` — выгрузка старой переписки (`scan_history.py`).
- `run.log` — журнал автозапуска.

## Команды
```
python3 send_outreach.py            # пробный прогон: что уйдёт сегодня (ничего не отправляет)
python3 send_outreach.py --check    # проверить ответы и недоставленные
python3 send_outreach.py --report   # сводка по статусам и ящикам
python3 crm_sync.py                 # пересобрать crm/crm.csv
python3 scan_history.py --months 12 # выгрузка переписки для поиска «зависших» клиентов
python3 build_emails.py leads.csv emails_template.md emails_wave1.csv
```
У каждого скрипта есть `--help`.

## Правила
- Ответившим отвечай сам; цепочка по ним уже остановлена. «Нет» или «отпишите» — больше не пишем. Недоставленные не повторяем.
- Прогрев ящика: 10 → 15 (с 3-го дня) → 20 (с 7-го) → 30 (с 14-го) писем в день; всего не больше `daily_limit_total` (60).
- Автопауза ящика на 72 ч при недоставке больше 8% адресатов за 14 дней (от 10 адресатов); на 20 ч при ошибке отправки.
- Много недоставленных или письма в спаме — остановиться и разобраться (см. references/deliverability.md).
