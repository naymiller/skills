# Цепочки писем — шаблон (пример, замените под свой оффер)

Отправка: с ящика рассылочного домена через Яндекс 360, обычный текст, от имени {sender_name}.
Расписание: письмо 1 → через 3 дня письмо 2 (с КП во вложении) → через 7 дней от первого письмо 3 → через 14 дней письмо 4. Любой ответ останавливает цепочку.
Плейсхолдеры: {company} — название, {hook} — персональная первая строка с проверяемым фактом, {offer} — одно предложение про вашу услугу, {sender_name} — имя отправителя (подставляет send_outreach.py из config.json).
Пустой {hook} или {offer} в leads.csv — абзац с плейсхолдером не выводится.

Логика каждого письма: проблема клиента → повод сейчас → как её закрывает ваша услуга → одно действие. Связь везде одна: ответить на письмо.
В каждом письме есть строка отписки. Ответ «нет» или «отпишите» — отписка навсегда.
