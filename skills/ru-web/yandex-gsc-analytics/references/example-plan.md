# ПРИМЕР плана «больше клиентов» (условный сайт example.ru)

> Пример. Сайт, цифры, запросы и цены условные. Структура — образец для собственного плана; свои цифры берутся только из выгрузки.

Период: 5 недель (условный). Счётчик Метрики и карточка Бизнеса — условные.

## 1. Что говорят данные
- Визитов всего 240, чистых после очистки 198 (из них 14 — визиты владельца и тесты, 28 — сканеры и повторы срабатывания формы).
- Из Яндекс-поиска 96 визитов, с целью 11 (11%); из AI-ассистентов 14 визитов, с целью 1 (7%); прямые 52 визита, с целью 4 (8%).
- Вебмастер: 40 коммерческих запросов с показами 12 000 в месяц в среднем по дням, CTR 0,6% на позициях 4–10 — показы есть, клики нет.
- Карточка Бизнеса: 310 визитов за год, переходов на сайт 38, звонков 9, сообщений в мессенджер 4.
- Форма: 6 ошибок за период, 5 из них на мобильных устройствах.

## 2. Рычаги по приоритету
| # | Рычаг | Ожидаемый эффект | Метрика проверки |
|---|---|---|---|
| 1 | Починить форму на мобильных (`reason.*` в параметрах визитов) | заявки с телефонов перестают теряться | число ошибок формы и отправок на 100 визитов |
| 2 | Посадочные под 3 коммерческих кластера с минимальным тиражом и ценой «от» в title | рост CTR на позициях 4–10 | CTR и клики по избранным запросам |
| 3 | Заголовок и description главной с конкретикой, без общих слов | рост кликов по запросу бренда и общих запросов | CTR главной в Вебмастере |
| 4 | Telegram, часы работы и 3 услуги с ценами «от» в карточке Бизнеса | переходы из карточки в мессенджер | цели «Переход в мессенджер» из карточки |
| 5 | Объединить 4 похожие статьи в одну страницу-сравнение, старые URL — 301 | меньше «малоценных» страниц в индексе | страницы в поиске, «малоценные» |

## 4. Что нужно от владельца
- Залить архив `ЗАГРУЗИТЬ-example.ru-seo-2026-11-05.zip` в папку `public_html` хостинга с заменой файлов.
- Подтвердить цены «от» для каждой услуги (в примере: «от N ₽ при тираже M шт»).
- Согласие на переобход новых страниц и отправку URL в поисковики.

## 5. Как мерить через 2–4 недели
- Повторить выгрузку тем же способом и сравнить с этим пакетом.
- Клики и CTR по избранным запросам; визиты из Яндекса; конверсия по цели «Отправил контактные данные» среди визитов из поиска; переходы из карточки в мессенджер.
- Выводы по выборке меньше 300 визитов — гипотезы, не итог.
