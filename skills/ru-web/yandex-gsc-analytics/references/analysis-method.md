# Метод анализа

Цель анализа — не «отчёт о трафике», а ответ на три вопроса: откуда приходят заявки, где теряются люди, что сделать первым. Все цифры — с периодом и оговоркой о размере выборки.

## 1. Очистка
Отметь и исключи, но не удаляй из пакета (аналитику нужны обе цифры):
- визиты владельца и тесты: параметры `_ym_debug`, `cachebust`, рефереры `metrika.yandex.ru`, `webmaster.yandex.ru`, `yandex.ru/sprav`, локальные адреса; uid с 5+ визитами за период; визиты в минуты правок сайта;
- сканеры: зарубежные страны (США, Германия, Нидерланды, Сингапур) с 1 страницей и 0 с; известные AI-краулеры;
- срабатывания одной формы под двумя целями (например, два блока формы с разными целями срабатывают по 10 раз за один визит) — считать визиты с целью, а не достижения.
Запиши в README: «153 визита → 118 чистых → ~95 посетителей».

## 2. Обязательные таблицы
1. **Источники → визиты → с целью → доля.** Отдельно Яндекс-поиск, Google, ChatGPT/AI (реферер chatgpt.com, perplexity, ya.ru/neuro), прямые (часть — AI без реферера), карты/Бизнес, сайты, внутренние. Конверсию считай по визитам с любой коммерческой целью (мессенджер, форма, email, звонок).
2. **Путь конверсионного визита:** какие страницы были в визитах с целью (главная / продукция / цены / контакты / калькулятор), сколько страниц и минут, устройство. Отсюда — что должно быть на первом экране.
3. **Динамика по неделям:** чистые визиты / с целью. Растёт конверсия или трафик.
4. **Кластеры запросов Вебмастера:** сгруппируй запросы по смыслу (коммерческие «пошив/производство/фабрика», бренд, информационные «что лучше/чем отличается», отдельные ниши); по кластеру — число запросов, показы за год, клики, ключевые запросы с позицией. Показы в `queries` — среднее в день, умножай на дни.
5. **CTR по позициям:** позиции 1–3 / 4–10 / 11–20 → показы, клики. CTR≈0 на 4–10 — проблема сниппета и посадочной, не позиции.
6. **Индексация:** страниц в поиске / добавлено / малоценные / дубли (каталог с одинаковыми карточками, статьи-дубли). Sitemap «не используется роботом», favicon, региональность.
7. **Карточка Яндекс Бизнеса:** визиты за год, переходы на сайт, маршруты, звонки, мессенджеры, отказы. Сравни с визитами из поиска на сайт.
8. **Форма и ошибки:** параметры визитов `reason.*`, `status.partial`, `lead_error`; доля мобильных среди ошибок.
9. **Поведение:** входы (доля главной), выходы, часы и дни конверсий, гео.
10. **Цели и измерение:** какие цели избранные, дубли, чего нет (избранных запросов в Вебмастере → нет истории позиций).

## 3. Типовые выводы (проверяй, не копируй)
- Поисковый визит конвертирует в разы лучше AI- и прямого → главный рычаг не «больше AI», а «кликабельность в поиске».
- Все показы идут на главную с общим title → нужны посадочные под кластеры и title с ценой «от», «от N шт», «свой цех».
- Информационный кластер даёт показы без кликов → одна сильная страница-сравнение с таблицей и кнопкой расчёта, дубли статей объединить.
- Спрос на отдельную услугу или нишу есть, страницы нет → страница на действующем сайте до запуска отдельного проекта.
- Карточка Бизнеса получает охват больше сайта, но не конвертирует → Telegram, услуги с ценами, часы, фото.
- Много почти одинаковых карточек каталога → риск «малоценных» страниц: объединить варианты или canonical.
- Форма ломается на мобильных → чинить до любых SEO-правок, иначе рост трафика не даст заявок.

## 4. Чего обычно нет в данных — честно перечисли
История позиций (нет избранных запросов), частотности Вордстата по кластерам, GSC по неподключённому сайту, Вебвизор старше 15 дней, точная атрибуция AI-трафика.
