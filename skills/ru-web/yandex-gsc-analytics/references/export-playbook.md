# Выгрузка: Метрика, Вебмастер, Search Console, Яндекс Бизнес

Выгрузка проверена на живых кабинетах во встроенном браузере агента. Владелец логинится сам; агент только читает кабинеты. На этапе выгрузки в кабинетах ничего не менять.

## Подготовка
- Реестр сайтов и счётчиков — файл `sites.md` рабочей папки. Пример записи: `example.ru | счётчик Метрики 00000001 | карточка Яндекс Бизнес 00000002 (ссылка yandex.ru/sprav/<id>/) | Вебмастер подтверждён | Search Console: аккаунт <почта>`. Номера счётчиков — только из кабинета, не придумывай.
- Период: 5 недель (с момента запуска сайта) для Метрики; 12 месяцев для Вебмастера и карточки. Если сайт новый — пиши «данных нет»: это тоже результат.
- Сначала проверь открытые вкладки. Если окно узкое (около 430 px), увеличь до 1400×1000: координаты скриншота масштабируются в кадр 800×571 (x·800/1400). В конце верни прежний размер окна.

## Метрика (`metrika.yandex.ru/stat/<отчёт>?id=<счётчик>&period=...`)
Отчёты, которые нужны всегда (`&view=Linear`, период явно): `sources` (источники, детально), `search_engines` (поисковые фразы), `entrance`, `exit`, `popular`, `titles`, `geo`, `hourly`, `tech_devices`, `deepness_depth`, `traffic` (по дням), `tags_utm`, `conversion_rate`, `visitors`, `visor`. Каждый коммерчески важный отчёт повтори с `&goal=<id>` для целей «переход в мессенджер», «отправил контактные данные», «клик по email», «клик на позвонить» и целей формы — так видно, какой источник даёт заявки.

Как читать:
- Текст таблицы — `get_page_text` после загрузки отчёта (подожди 2–3 с). Это основной способ, работает для всего.
- **История визитов целиком** (главный файл для анализа): официальный Logs API Метрики (нужен OAuth-токен владельца счётчика) или экспорт отчётов из интерфейса. Нужные поля визита: дата и время, источник трафика, поисковая система, реферер, UTM, устройство, регион, глубина, длительность, отказ, достигнутые цели, параметры визита. Недокументированные внутренние интерфейсы Метрики этот скилл не использует.
- Конфиг целей — из настроек счётчика (Цели) → сохрани как `metrika_goals_config.json` (нужны id целей для `&goal=`).
- Параметры визитов (ошибки формы `reason.*`, `status.*`) — отчёт «Параметры визитов».
- Избранные цели и звёздочки на этапе выгрузки не трогать.

## Вебмастер (`webmaster.yandex.ru/site/https:<домен>:443/`)
- `efficiency/queries` — все запросы: показы и клики там **среднее в день**, позиция, CTR; есть вкладка «по URL» (`queries_by_url`). Период переключай кнопкой «12 месяцев» в календаре: ручной адрес с датами часто даёт ошибку.
- `efficiency/statistics` — популярные запросы с итогами за период и прогнозом рекламного кабинета.
- `indexing/searchable` (страницы в поиске, «малоценные / исключённые»), `indexing/indexing` (обход), `indexing/sitemap`, `links/incoming`, `optimization/checklist`, `diagnostics`, сводка.
- Текст страниц забирай `get_page_text`; длинные таблицы — прокрути до конца или увеличь «показывать по».

## Google Search Console (`search.google.com/search-console`)
Аккаунт — тот, что записан в `sites.md`. Ресурсы: эффективность за 3 месяца (запросы, страницы, страны, устройства), индексирование страниц, файлы sitemap. Если домена нет в аккаунте — не добавляй его при выгрузке, запиши в README «не подключён». Подключение нового ресурса — отдельное действие, и только с согласия владельца.

## Яндекс Бизнес (`yandex.ru/sprav/<id>/p/edit/...`)
- Статистика карточки живёт в Метрике отдельным счётчиком: отчёты `sources`, `traffic` помесячно, цели «Переход на сайт», «Построить маршрут», «Клик на позвонить», «Переход в мессенджеры и соцсети».
- Данные карточки: `/p/edit/` (режим работы, сайт и соцсети, телефоны, особенности), `/p/edit/price-lists/` (товары и услуги), `/p/edit/photos/`, `/p/edit/reviews/`, `/p/edit/changes/` (история). Выпиши, чего нет: Telegram, услуги с ценами, фото, описание.

## Передача данных в рабочую среду
Рабочая среда агента часто не достаёт до сайтов владельца и кабинетов (прокси). Поэтому:
1. В странице: `JSON.stringify(data)` → `CompressionStream('gzip')` → base64 → вывести как
   ```
   @@BLOCK <сайт>|<отчёт>|<вариант>@@
   <base64 или текст>
   @@END@@
   ```
   `вариант` = `json` для JSON, `all` без цели, `goal_<имя>` для среза по цели, `txt` для текста.
2. В рабочей среде: `python3 scripts/extract_blocks.py <папка_raw> [transcript.jsonl]` вытаскивает блоки из транскрипта сессии; поздний блок с тем же именем побеждает. Затем `python3 scripts/build_package.py <папка_raw> <папка_package> --date <ГГГГ-ММ-ДД>` → `package/<сайт>/…`, санитайзер заменяет частично замаскированные телефон и e-mail из форм на `CONTACT_ENTERED:*`.
3. Проверь полноту: список файлов ниже. Для карточки Бизнеса достаточно источников, целей и помесячного трафика.

## Состав пакета (пример: сайт с одним счётчиком и карточкой Бизнеса)
```
README.md, ANALYSIS_yandex.md
<сайт>/metrika_visits_all.csv            все визиты, по строке на визит
<сайт>/metrika_visits_with_goals.csv     только визиты с целями
<сайт>/metrika_visitors.csv              посетители за год (uid, визиты, устройства, цели)
<сайт>/metrika_goals_config.json         id и условия целей
<сайт>/metrika_{sources,search_engines,entrance,exit,popular,titles,geo,hourly,tech_devices,deepness_depth,traffic_daily,tags_utm,goal_params}.txt
<сайт>/metrika_<отчёт>_<вариант>.txt     срезы по целям
<сайт>/webmaster_{dashboard,queries,queries_by_url,queries_positions_12m,popular_queries_full,popular_queries_12m,statistics,searchable,searchable_all,excluded,indexing,links_incoming,diagnostics}.txt
<сайт>/google_sc_{performance,index}.txt
<сайт>_card/metrika_{sources,traffic_monthly}.txt + срезы по целям карточки
```
README пакета: период и дата, список целей с id, маркеры внутренних визитов (uid владельца, `_ym_debug`, `cachebust`), оговорки. Типовые оговорки: трафик из AI-ассистентов недосчитан (часть «прямых» визитов — ассистенты без реферера); показы Вебмастера — среднее в день; Search Console не подключён, если так.

## Грабли
- `browser_batch` с прокрутками, JS и скриншотом может быть заблокирован классификатором — делай по одному действию.
- JS-`click()` не всегда доходит до React: звёздочку избранной цели и кнопки «Сохранить» нажимай реальными координатами. Значения в поля React ставь через `form_input` или нативный сеттер и событие `input`.
- Кнопка «Сохранить изменения» в Яндекс Бизнес скрыта, пока поле не потеряло фокус — после ввода нажми Tab.
- Вебвизор хранит записи 15 дней; история визитов через API доступна за весь период счётчика.
