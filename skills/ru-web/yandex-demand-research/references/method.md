# Кластеризация и решения

## Таблица `research/queries.csv`
`query, exact, broad, region, intent, cluster, page, top_domains, ours, source`
- `intent`: commercial (заказать, цена, производство, фабрика, пошив), info (что лучше, чем отличается, как), nav (бренд, адрес), niche (нишевые варианты услуги).
- `cluster` — имя группы по смыслу, а не по словоформе: «пошив мерча», «производитель мерча», «малый тираж», «сравнение методов», «цены». Запрос попадает в один кластер.
- `page` — URL-кандидат. Один кластер = одна страница. Один запрос не может вести на две страницы.
- `ours` — есть ли у нас страница под кластер и какая позиция в Вебмастере, если есть.

## Правила
1. Приоритет кластера = спрос × конвертируемость × достижимость. Коммерческий кластер, где в топе локальные производства, а не агрегаторы, — первый. Кластер, по которому сайт уже показывается на позициях 4–20, — тоже первый (дешевле всего).
2. Кластер без заметного спроса (единицы показов) → вопрос в FAQ родственной страницы, не отдельная страница. Дробить сайт на десятки тонких страниц нельзя: Яндекс отмечает их как малоценные.
3. Информационные кластеры → статьи-сравнения с таблицей и кнопкой расчёта или заявки. Одна статья на кластер, без дублей с разными title.
4. Нишевые кластеры → отдельная страница только при спросе и реальном предложении; иначе раздел на странице услуги.
5. Тиражные страницы («от N штук») — только если эти фразы есть в подсказках и Вордстате, и каждая со своим расчётом и примером.
6. Title ≤ 65: главный запрос + конкретика, которую конкуренты выносят в сниппет (цена «от», «от N шт», «свой цех», город). Description 140–160 с цифрами. Главная — под самый широкий коммерческий кластер, остальное — на посадочные.
7. Слова людей (подсказки, PAA, отзывы) → H2, FAQ, первый экран. Профессиональный жаргон — вторым, если люди его сами не используют.
8. Для каждой страницы передай в сборку факты, которые спрашивают люди и нейросети (цена «от», минимальный тираж, срок), и список вопросов для FAQ из спроса. Как оформить страницу и тексты — решает автор сайта по своим правилам.

## Что передать в сборку сайта
- Карта страниц → список страниц, H1, title и description (без пересочинения).
- FAQ-вопросы → блок FAQ.
- Факты для `llms.txt` и `llms-full.txt`, блок с ответом.
- Список ботов и закрытых путей → `robots.txt`.
- Запросы для избранных в Вебмастере после запуска → список для контрольной точки.
