# Видео — персональные требования, не upstream skill

Основы: higgsfield-generate, higgsfield-video-explainer; soul-id только при реальной необходимости.

## Фото в видео
Выбрать одобренный кадр. Зафиксировать длительность, формат, действие, движение камеры,
неизменные признаки изделия/лица и требования к звуку. Проверить наличие image-to-video/start/end frames
у конкретной модели. Не передавать reference flags текстовой модели, которая их не поддерживает.
Пилотный короткий клип → просмотр → исправления → согласованная серия.

## Рекламный ролик
Бриф → аудитория/оффер → hook → сценарий → раскадровка → ключевые кадры → шоты → монтаж/субтитры.
Marketing Studio — проверенный вариант только если функция доступна в выбранном аккаунте/контуре.
Не изображать синтетический UGC как реальный подтверждённый отзыв покупателя.
Не выдумывать цифры, скидки, сертификаты, результаты и характеристики товара.

## Объясняющее видео
Использовать официальный video-explainer workflow при доступности. Проверить стиль, язык озвучки,
произношение бренда, совпадение narration со сценами и финальную сборку. Это отдельная цепочка,
а не обещание смонтировать любое произвольное видео данным skill.

## Приёмка
Просмотреть ролик, а не только HTTP-ответ. Проверить начало/конец/переходы и весь ролик по возможности:
плавность, деформации, анатомию, логотип, мерцание, continuity, читаемость текста, звук и синхронизацию.
Проверить реальные длительность, разрешение, FPS, кодек и наличие аудио доступными инструментами.
FFmpeg/ffprobe устанавливать только при необходимости и с разрешения; не считать их установленными.
Virality Predictor трактовать как оценку сервиса, не доказательство будущих просмотров/продаж.
Выдать конечный MP4 и исходные шоты, если доступны, журнал и ограничения. Ничего не публиковать.
