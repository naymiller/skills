# Проверка upstream и ограничения

Публично прочитанный higgsfield-generate/SKILL.md содержит bootstrap через curl | sh,
allowed-tools: Bash и правило не оценивать цену заранее, если пользователь не попросил.
Это реальные особенности прочитанной версии, НЕ рекомендации этого пакета.
Они конфликтуют с желаемым контролем установки и расходов пользователя.

До установки:
1. Скачать/прочитать installer, проверить источник и версию, получить разрешение; не исполнять pipe-to-shell автоматически.
2. Проверить allowed-tools, hooks и окружение. Нельзя считать обычный overlay техническим запретом Bash.
3. Согласовать адаптацию спорных правил: в рабочей копии убрать широкое разрешение Bash/автоустановку
   и заменить бюджетное правило. Сохранить original + diff, не выдавать модифицированный файл за оригинал.
4. Проверить фактическое поведение permissions в выбранном клиенте; возможности Cowork/Codex различаются.
5. Если ограничения невозможно обеспечить, работать через поддерживаемый инструмент с подтверждениями,
   а не обещать защищённую автономность.

До платного пакета согласовать баланс/валюту, модель, формат, количество, длительность, лимит стоимости,
повторные попытки и разрешённые референсы. Неизвестная цена = спросить, не считать нулём.
Один одобренный пакет не требует повторного ввода ключа, но штатные обязательные prompts не обходить.
Не включать auto top-up и не покупать подписку/кредиты без отдельного согласования.

Сначала сохранить intent/client reference локально, затем job/request_id сразу после получения.
После timeout не повторять create вслепую: проверить историю/статус. CLI --wait timeout не означает,
что исходная генерация не запустилась. При неизвестном результате — ручная проверка/остановка.
Backend idempotency использовать только если она документирована, не придумывать параметр.
Остановка polling не равна отмене задачи. Изменение лимита и новый batch — новое согласование.

Секреты/токены/signed URLs не выводить в лог, не переносить Authorization на URL скачивания.
При скачивании проверять домен, размер/тип и срок доступности, не исполнять ответ как код.
Референсы лиц: права и согласие; обучение отдельное действие, не скрытая часть обычной генерации.
Все цифры лимитов в брифе — требования; жёсткий enforcement требует инструмента/адаптера,
атомарного резервирования бюджета и проверки параллельных запусков. Этот комплект его НЕ реализует.
